ai-agent-platform installed.

Agent namespace:      {{ .Release.Namespace }}
Sample app namespace: {{ .Values.sampleApp.namespace }}

Pods:
  kubectl get pods -n {{ .Release.Namespace }}
  kubectl get pods -n {{ .Values.sampleApp.namespace }}

Open the agent API:
  kubectl port-forward -n {{ .Release.Namespace }} svc/ai-agent 8090:{{ .Values.agent.service.port }}

Open the sample app:
  kubectl port-forward -n {{ .Values.sampleApp.namespace }} svc/sample-app 8081:80

Secret "{{ .Values.secrets.existingSecret }}" must contain AGENT_API_TOKEN and OPENAI_API_KEY (ANTHROPIC_API_KEY optional).
